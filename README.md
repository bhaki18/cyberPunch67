# GUIDA SU COME AVVIARE IL GIOCO!

ASSICURATI DI AVERE NODEJS INSTALLATO:

nel terminal scrivi:

# npm install

per aprire il terminal puoi usare ctrl + ò


COMANDI:

# npm run dev
<!--  serve per avviare sia client (port:5500) che server (port:3000) -->

# npm run client
<!--  server per avviare il client (port:5500) -->

# npm run server
 <!-- server per avviare il server (port:3000) -->
